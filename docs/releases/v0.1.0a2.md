# SOVYN v0.1.0a2 — Hardening Draft

This release hardens the public alpha after Windows + Ollama + `qwen3:8b` E2E testing.

## Fixes

* Added Ollama thinking control and defaulted SOVYN agent calls to `think: false`.
* Added debug-only latency timing for model turns, tool calls, and total task duration.
* Reused identical successful read-only tool calls when the workspace has not changed.
* Invalidated read caches after workspace mutation.
* Changed workflow creation to explicit opt-in with `[y/N]`.
* Added workflow name validation so workflow files cannot escape `~/.sovyn/workflows`.
* Added canonical `sovyn config show` and `sovyn config select` subcommands.
* Added `python -m sovyn` as a Windows PATH fallback.
