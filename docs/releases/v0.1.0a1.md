# SOVYN v0.1.0a1 — Public Alpha

This is the first public alpha of SOVYN.

## Highlights

* Terminal-native interactive agent
* Local-first / bring-your-own-key model providers
* Filesystem, shell, git, HTTP, and Python tools
* Explicit permission system
* Workspace trust
* Session and trajectory recording
* Reusable workflows
* Provider normalization
* Path, shell, and network safety gates
* Benchmark and provider diagnostics

## Known Limitation

Real Ollama tool-calling was not manually verified on the release machine because Ollama was not installed.

## Notes

This is an alpha release. Provider behavior varies by model, workflows intentionally use a small schema, and SOVYN is not a sandbox for arbitrary shell execution.
